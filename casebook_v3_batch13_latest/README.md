# Casebook V3 — latest-notes remake batch (13 packs)

Folders:
- `packs/`: thirteen complete V3 JavaScript packs.
- `docs/`: governing specifications, archetype changelog, cohesion sheets, and audits.
- `tools/`: `validate_casebook_v3.js`.

Validate from this directory with:

```bash
node tools/validate_casebook_v3.js "$PWD"/packs/*.js
```

All packs use three informants, three readings, three questions per reading, and one WHO/WHAT/WHERE clue per reading. Candidate and expert-answer positions are deliberately varied across the batch.
