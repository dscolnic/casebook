PLACES — one file per campaign, listing every location a question can be asked at.

Generated 2026-09-05 from each theme's own site.js/plan.js, fixtures.js, minors.js,
content/groups.js and theme.js. Regenerate rather than hand-editing: those source
files are the description of the place, and a second copy of a rule drifts the
first time either is corrected.

Each file carries: why the place is that place (the source file's own prose, which
is where the reasoning already lives), the areas with their group, position,
distance from spawn and calls, every fixture with its build/wall and any day gate,
the enterable non-areas, the landmarks that carry the place but no lesson, the
delivery pieces, and the authoring rules.

"fixtured" counts the rooms with named at: targets. A campaign with none asks every
question at the case stand.
