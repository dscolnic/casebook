FunWhat this subject and this place can carry

SPOT

stronga FLIGHT or STRUCT stop

A flight rule is a standing instruction, written on the board, and it is replaced mid-shift when the vehicle changes state. No other game in the set has a literal, historically accurate home for this format.

serves
flight rules and the cost of not noticing a change
needs
two instructions, at least two changes, and items only one of them wants

HOLD

strongNAV or STRUCT

Hold attitude rate inside a closing band while a leaking thruster pushes. The game already carries one FLY, and the argument that made FLY work — bounded commands on undamped dynamics, the brake has to lead — is the same argument one step harder.

serves
concept 6, circular motion and centripetal force, off the select-only list
needs
a do-nothing run must fail; integrate the disturbances with the control untouched

SWEEP

strongstop 8 · NAV

"Small burn, large consequence" is a BALLPARK. Burn duration against arrival error is a curve with a minimum, and the point of the stop is that the curve is steep.

serves
impulse as the change in momentum, made visible
needs
the response plotted only where the player looks

TALLY

mediuma THERM or STRUCT stop

Telemetry samples accumulate and the trend firms up. Right subject, and the room is full of plot boards to put it on. Medium because the game’s CLOUD stop already argues about width.

serves
measurement noise against a real trend

The order of work

1. Phase 0 — teach the coverage check to read an instrument’s own board, and re-baseline curriculum-debt.json. Rewriting a stop that already teaches the thing is the exact failure the check exists to prevent. 2. Snapshot. 3. Edit the book, never the generated content — tools/import-book.mjs books/bring-them-home.yml bring_them_home --verify. 4. npm run traps: every instrument’s trap must fire. 5. npm run check bring_them_home and npm run drive bring_them_home, right answer and wrong — ask what a player who understood nothing would score before believing any pass mark. 6. --against the snapshot. A changed format is reported; a changed objective fails.
