ReadingWhere this campaign stands

Two of the four gaps are not gaps but absences: Rₑ = R₀ × S and CFR = deaths / cases are mentioned at no stop at all. An AP Biology public-health course that never reaches the effective reproduction number is missing its spine. The mix is healthy — SEQUENCE-led, twelve of them — so this campaign’s work is almost entirely curriculum.

TALLY

stronga POP stop

Cases accumulate into bins and the statistic moves because there is not enough behind it yet, not because the epidemic changed. That confusion is the single most consequential error in outbreak reporting, and it is what TALLY grades.

serves
Rₑ and CFR — the two equations the game does not have
needs
a run where an early batch flatters the number, and a pass mark that stays unprinted

TRIAL

strongthe decon tunnel

The place already has the lesson built into it: courtyards, triage marquees, container labs, a decon tunnel on the main route and a fence with one gate. Driving that route in the wrong order is how a campus infects itself.

serves
transmission and barrier practice; the place stops being scenery
risk
gates stood off each door by d/2 + 10, or every ring renders under the floor

The order of work

1. Phase 0 — teach the coverage check to read an instrument’s own board, and re-baseline curriculum-debt.json. Rewriting a stop that already teaches the thing is the exact failure the check exists to prevent. 2. Snapshot. 3. Edit the book, never the generated content — tools/import-book.mjs books/outbreak-riverton.yml outbreak_riverton --verify. 4. npm run traps: every instrument’s trap must fire. 5. npm run check outbreak_riverton and npm run drive outbreak_riverton, right answer and wrong — ask what a player who understood nothing would score before believing any pass mark. 6. --against the snapshot. A changed format is reported; a changed objective fails.
