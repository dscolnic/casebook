TALLY

strongstop 8 or 32 · COLD / CORE

Counting annual layers until the date is defensible is ice-core dating, and it is the same decision TALLY grades: when is there enough behind the number to report it.

serves

The order of work

1. Phase 0 — teach the coverage check to read an instrument’s own board, and re-baseline curriculum-debt.json. Rewriting a stop that already teaches the thing is the exact failure the check exists to prevent. 2. Snapshot. 3. Edit the book, never the generated content — tools/import-book.mjs books/icecore.yml icecore --verify. 4. npm run traps: every instrument’s trap must fire. 5. npm run check icecore and npm run drive icecore, right answer and wrong — ask what a player who understood nothing would score before believing any pass mark. 6. --against the snapshot. A changed format is reported; a changed objective fails.
