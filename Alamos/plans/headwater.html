ReadingWhere this campaign stands

Nothing is wrong with this campaign. All fifteen equations computed, no debt, no select-only concepts at all, no absent concepts, and four OPERATE stops — the most in the set. It already carries SWEEP, PROBE, HOLDOUT, RESIDUAL and PROPAGATE. It is the worked example of what every other plan in this set is aiming at, and it is included here only because the question was asked of every high-school campaign.

Everything below is therefore a fun argument and nothing else. There is no curriculum case for any of it, and if the schedule is short this is the campaign to skip.

Protected — do not convert

All thirteen DERIVE stops stay. Headwater is AP Calculus AB and the derivation rail is the course. Nothing below touches one.

HOLD

stronga gate-chamber stop

The best HOLD available in the catalogue. Hold the reservoir inside a closing band while an inflow surge arrives and you work the gates — rate in against rate out, which is the fundamental theorem with a hundred metres of air off the crest if you get it wrong. The game is a dam; the format is a dam.

The order of work

1. Phase 0 — teach the coverage check to read an instrument’s own board, and re-baseline curriculum-debt.json. Rewriting a stop that already teaches the thing is the exact failure the check exists to prevent. 2. Snapshot. 3. Edit the book, never the generated content — tools/import-book.mjs books/headwater.yml headwater --verify. 4. npm run traps: every instrument’s trap must fire. 5. npm run check headwater and npm run drive headwater, right answer and wrong — ask what a player who understood nothing would score before believing any pass mark. 6. --against the snapshot. A changed format is reported; a changed objective fails.
