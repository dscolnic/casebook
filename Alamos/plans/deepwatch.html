FunWhat this subject and this place can carry

PROBE

strongstop 9 · SONAR

"Where the sound will not go" is a CHOICE. PROBE hands over no readings: take the sound-speed profile depth by depth and find where the ray bends away. The shadow zone is not the depth with the worst number on it, which is the format’s own sentence.

serves
Snell’s law and concept 25 — the largest single gap in the game
needs
a profile with one honest break and a plausible decoy

SWEEP

strongstop 12 · ENG

"The one shaft speed that rings" is a CHOICE, and resonance is select-only. A resonance is the canonical SWEEP: drag shaft speed, watch vibration, and the peak is somewhere in a curve nobody drew for you.

serves
concept 5, resonance and harmonics
needs
a narrow peak that is genuinely findable and not marked

HOLD

strongENG or CTRL

Hold trim or depth inside a closing band while flooding pushes. This is the one thing the port from deep_watch/ deliberately dropped — a rate that rises while you read a gauge had nowhere to live in walk-answer-hand-off. HOLD is where it lives.

serves
buoyancy and control; recovers a simulation the port lost
needs
rate × time authored so a do-nothing run fails

TRIAL

strongthe compartment line

Ten compartments, hatches between them, no sky. A casualty route driven in the order that does not spread the fire, graded on order and not the clock. The game already carries a ROUTE, which is the seated version of this.

serves
casualty procedure and compartment dependency
risk
the boat is its own world module; gates need the theme’s own geometry

SPOT

stronga SONAR watch stop

A standing order changed mid-watch, with nothing announcing it. Submarine watchkeeping runs on standing orders; the cost of missing a change is the format’s whole subject.

serves
watch discipline and contact classification

TALLY

mediumstop 25 or 36

Pings accumulate into a bearing rate, and early on it moves because there is not enough behind it. Good, and it competes with the two SONAR BALLPARKs already there.

serves
detection statistics

The order of work

1. Phase 0 — teach the coverage check to read an instrument’s own board, and re-baseline curriculum-debt.json. Rewriting a stop that already teaches the thing is the exact failure the check exists to prevent. 2. Snapshot. 3. Edit the book, never the generated content — tools/import-book.mjs books/deep-watch.yml deepwatch --verify. 4. npm run traps: every instrument’s trap must fire. 5. npm run check deepwatch and npm run drive deepwatch, right answer and wrong — ask what a player who understood nothing would score before believing any pass mark. 6. --against the snapshot. A changed format is reported; a changed objective fails.
