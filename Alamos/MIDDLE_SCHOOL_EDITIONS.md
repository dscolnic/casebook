# Middle-school editions — the same games, a different course

Fourteen of the sixteen games get a **grade-6 edition**: same place, same cast,
same story, a different course taught inside it. This file is the plan and the
contract. `gamekit/NEW_GAME.md` is how a *new* game is built; this is how an
existing one is re-taught.

The one-line version:

```sh
cd gamekit
node tools/derive-edition.mjs planetary_defense              # print the day sheet, choose ten
node tools/derive-edition.mjs planetary_defense --days 1,2,4,5,6,8,9,12,14,15
npm run check planetary_defense_ms          # red on reading level — that is the work list
npm run export-stops planetary_defense_ms   # the sheet the writing pass edits
node tools/edition-addendum.mjs planetary_defense_ms --write   # the page that goes with it
```

---

## 1. What an edition may change, and what it may not

**An edition is content. The place and the people are frozen.**

A middle-school theme directory holds exactly four things:

```
themes/<base>_ms/
  theme.js          ~40 lines, derived from the base manifest
  site.js           one line: export { site } from '../<base>/site.js'
  (or plan.js)      whichever the base has
  content/          generated by tools/import-book.mjs from books/<base>-ms.yml
```

Anything else in that directory is a fork and `editionParity.mjs` fails the
game for it. In particular an edition never carries `world.js`, `props.js`,
`interiors.js`, `outfits.js` or `shots.js` — it imports the base's.

Frozen across the pair, all asserted:

| Frozen | Why it cannot move |
| --- | --- |
| every group's `id`, `code`, `name`, `color`, `defaultLeader` | a group is a building. Drop one and a building has nothing in it, which `worldParity` calls unreachable |
| every roster `id`, `name`, `role`, `place`, avatar | the cast is the texture of the game. Only `bio` prose and `quiz` are rewritten |
| `title`, `dayNoun`, `stopNoun`, `site.spawn`, every `stop.place` | the player is standing in the same world |
| the campaign argument | both named antagonists still win a day, or the player learns a slogan (`STORY_SPEC.md` §1) |

Free to change: every sentence, every question, every format, the day titles,
the ten days chosen out of fifteen, the glossary, and the course itself.

**A dropped unit does not drop its group.** If the grade-6 course has no
equilibrium in it, Reactor Hall still gets stops — retargeted to something a
sixth grader can learn standing in that room. The building is the constraint;
the subject is not.

## 2. Why a separate theme id, and not a build flag

`redsand_ms` is a registered theme with its own directory, and its book is
`books/redsand-ms.yml` — in `books/` rather than a subdirectory, because
`bookParity.mjs` finds a theme's book by matching the separator-free spelling of
its name against that one directory, and `redsand_ms` matching `redsand-ms.yml`
is what lets the parity check cover editions without being told about them. The alternative —
one theme, an `EDITION=` env var and an `@content` alias — was rejected for
three reasons, in order of how expensive they are:

1. **The save key is `gamekit_${theme.id}_v1`** (`engine/core/constants.js`),
   and `cloudSave.js` posts `theme=<id>`. Two editions sharing an id share a
   save slot, and house rule 14's guard cannot catch it: the group ids are
   *deliberately identical*, so the rejection test that saved the hospital says
   this save is fine. A ten-day campaign would load into a fifteen-day one.
2. **Every dev tool resolves `themeDir` from `themes.json` and reads
   `content/missions.js`.** A registered theme gets all sixteen checks, `drive`,
   `instruments.html`, the gallery and the casebook sync for free. An edition
   flag means patching sixteen tools that currently name no theme at all.
3. Lookups in `tools/syllabus.js` are all `?? []`, so a new key is additive.

The cost is one change in `vite.config.js`: an edition's `site.js` is a
re-export, so the `declaredKind` and `ownWorld` regexes find nothing. A
`// edition-of: <base>` header on the manifest tells vite to read the kind and
the world out of the base theme's directory instead.

## 3. The pipeline

```sh
cd gamekit

# 1. choose the ten days — it refuses to guess, and prints the fifteen
node tools/derive-edition.mjs <base>

# 2. derive — base prose verbatim, playable immediately
node tools/derive-edition.mjs <base> --days 1,2,4,…
#    writes books/<base>-ms.yml, themes/<base>_ms/, registers it, imports it

# 3. the sheet, and the page that goes with it
npm run export-stops <base>_ms
node tools/edition-addendum.mjs <base>_ms --write

# 4. hand books/GRADE6_BRIEF.md + books/convert/<base>_ms-addendum.md + the sheet
#    to the writing pass

# 5. back it comes
node tools/check-conversions.mjs <base>_ms <returned>.jsonl
node tools/apply-conversions.mjs <base>_ms <returned>.jsonl
node tools/import-book.mjs books/<base>-ms.yml <base>_ms --verify
npm run check <base>_ms && npm run drive <base>_ms
```

`npm run shots` is deliberately **not** in that list. The place is identical to
the base game's; a contact sheet of it already exists.

**The derived baseline is playable but not green.** It carries the senior-high
prose against a grade-6 manifest, so `validateContent` fails it on reading
level from the first run. That is not a bug in the scaffold — it is the work
list, and `derive-edition` prints the count of failing passages as the estimate
of the job. Everything structural is green from minute one: the campaign is
reachable, the questions grade, the places exist.

### The day map

Ten days out of fifteen is a decision per game, so `derive-edition` refuses to
guess. Run it with no `--days` and it prints the fifteen days with their groups
and their argument beats, and stops. The selection has to satisfy:

- every group keeps at least one room stop (hard failure);
- both sides of the campaign argument keep the day they win (`STORY_SPEC.md`);
- the first day and the last day are kept, because they open and close the story.

## 4. The course, per game

`tools/syllabus.js` gains a `<base>_ms` entry: 12–16 concepts rather than 30,
and a grade-6 `EQUATIONS` list with its own `needs` dependencies. Without it
`equationOrder` and `syllabusEquations` pass by measuring nothing, which is the
exact failure mode CLAUDE.md's readability section is about — a measurement
that asserts nothing about itself reports confident numbers for weeks.

Allowed grade-6 mathematics: ratios and unit rates, decimals, fractions and
percentages, means of repeated measurements, scale factors, substitution into a
one-line formula, `speed = distance / time`, `rate × time`. Not allowed:
derivatives, integrals, logs, trigonometry, statistical inference, equilibrium
constants, phasors, vectors.

| Game | Senior-high course | Grade-6 course | Scale |
| --- | --- | --- | --- |
| Deep Watch | waves & sound | sound, echo, wave properties, density and buoyancy | direct |
| Aftershock | statics & earth science | plates, quakes, seismic waves, design | direct |
| Ice Core | earth & environmental | layers as time, averages, graphs, the carbon cycle | direct |
| Planetary Defense | astronomy · mechanics | solar-system scale, orbits, brightness, ratios | direct |
| Wellmere | AP Biology · heredity | traits, Punnett squares, selective breeding | trim |
| Outbreak: Riverton | AP Biology · public health | transmission, rates per 1000, graphs | trim |
| Blackout | circuits & induction | circuits, series and parallel, kWh, generators | trim |
| Bring Them Home | AP Physics 1 | speed and time, rate × time budgets, energy transfer | trim |
| The Contaminated City | AP Chemistry · analytical | mixtures, concentration as a ratio, filtration, averaging | heavy trim |
| Red Sand | AP Chemistry · back half | conservation of mass, physical and chemical change, what makes a reaction fast | heavy trim |
| The Trial | AP Statistics | fair tests, control groups, sample size, mean and spread | **redesign** |
| Safety Factor | AP Physics 1, via DERIVE | forces, speed, energy, safety margin as a ratio | **redesign** |
| Headwater | AP Calculus AB | unit rates, slope as steepness, volume = rate × time | **redesign** |
| Hospital Heroes | anatomy (grade 2) | the same body, with ratios, percentages and controlled comparison | **upward** |

**Quantum and Project Y have no middle-school edition.** Quantum because
nothing at grade 6 supports a two-level system and a softened version would be
pseudo-science; Project Y because of its subject matter, not its difficulty.
Both stay senior-high only, and the level toggle simply shows fewer cards.

**`DERIVE` is banned below grade 9.** Its whole job is algebraic manipulation.
The reasoning it carries survives in `BALANCE` (close the ledger), `ALLOCATE`
(a finite pool), `CLOUD` (a spread against a limit), `TALLY` and `PROBE`.

**Hospital Heroes is the one upward conversion**, grade 2 to grade 6: content
gets harder, not simpler, and the type scale drops 1.18× to 1.10×. The brief is
written throughout for scaling *down*, so that game is written last, after the
pipeline has been proved on the other thirteen, and gets its own addendum.

## 5. The brief

`CONVERSION_BRIEF_GRADE6_10MISSIONS.md` at the repo root is one pass, written
around Planetary Defense, and still carries grade-5 text in §5 rule 8. It
splits:

- **`gamekit/books/GRADE6_BRIEF.md`** — the general grade-6 brief. Adds the
  freeze contract from §1 above, the `DERIVE` ban, and the requirement that a
  book author `— Review` lesson variants, since days 3–10 all carry callbacks
  and nothing reaches a review lesson that does not exist.
- **`tools/edition-addendum.mjs <theme>_ms`** — generated per game: the grade-6
  syllabus, the equations allowed, the concepts forbidden for that subject, the
  cast with roles so nobody arrives as a bare surname, the argument and whose
  day is whose, and the ten day titles.

## 6. The front doors

`tools/games.js` is the catalogue both front doors read. Each row gains:

```js
level: 'middle' | 'high' | 'elementary',
pair:  '<base id>',     // the same game at another level
grades: '6–8',
build: '<theme id>',    // which dist/ directory the card opens
```

- `tools/gallery.mjs` draws a three-way control — Elementary · Middle School ·
  High School — filters the cards, remembers the choice, and accepts
  `?level=middle` as a deep link.
- `tools/sync-casebook.mjs` writes the same fields into `games.json` and takes
  `--level middle|high` so one set can be rebuilt alone. **Sixteen builds
  becomes thirty**, so a full sync roughly doubles.
- The casebook shelf's own HTML lives in `~/code/casebook` and needs a small
  patch of its own to read the fields and group completion rows on `pair` —
  otherwise `redsand` and `redsand_ms` appear as two unrelated games in a
  player's history. That is a change in that repo, not this one.

Midway (*Safety Factor*) has no row in `tools/games.js` at all and therefore
appears on neither front door today. It gets one in the same pass.

## 7. What is built

The machinery is in, and Planetary Defense is derived and playable at grade 6.

| Piece | Where | What it does |
| --- | --- | --- |
| `derive-edition.mjs` | `tools/` | day sheet, then a ten-day book, a manifest, the shims, the registration and the import |
| `editionParity.mjs` | `engine/dev/` | the freeze contract, inside `npm run check` |
| `edition-addendum.mjs` | `tools/` | the per-game page: cast, areas, syllabus, equations allowed and forbidden, the ten days, the argument |
| `placeDir()` | `engine/dev/registry.mjs` | six tools now read the *base* theme's place |
| `// edition-of:` | `vite.config.js` | site kind and world module resolved from the base |
| `cards()` | `tools/games.js` | one entry per build; `level`, `pair`, `grades`, `shotsFrom` |
| the level control | `tools/gallery.mjs` | Elementary · Middle School · High School, remembered, `?level=middle` |
| `--level` | `tools/sync-casebook.mjs` | build and ship one set at a time |
| `planetary_defense_ms` | `tools/syllabus.js` | 16 grade-6 concepts and 5 equations it may compute |

`planetary_defense_ms` currently fails `npm run check` on 54 reading-level
problems, 2 characters introduced by surname, 2 undefined hard words and the
opening card. That is the derived state, and it is the punch list for the
writing pass — nothing structural is wrong: the campaign plays end to end (10
days, 38 stops with callbacks), every question survives all four probes, the
book regenerates the content, and `editionParity` is green.

Still to do on the machinery: the casebook shelf patch, and `npm run drive`
against the edition once its instruments exist.

## 8. Order of work

1. **Machinery** — `derive-edition.mjs`, `editionParity.mjs`, the vite
   `edition-of` resolution, the catalogue fields. No content.
2. **Pilot: Planetary Defense**, end to end, including the toggle. It already
   has a grade-6 brief written for it.
3. **Deep Watch and Aftershock** — two direct scalers, to confirm the brief
   generalises past the game it was written around.
4. The trims, six games, each with its `_ms` syllabus authored first.
5. The three redesigns.
6. `hospital_ms`, the upward one, last.

Fourteen editions × 30 stops is **420 authored stops**. The machinery is days;
the writing is the project.
