Modern and minimalist this time, in the NYT Games family: white space, flat color, strong type hierarchy, no skeuomorphism. Same accessibility bar as before — every color pair verified ≥ WCAG AA (most AAA), 44px+ targets, visible focus rings (tab through to test), no state conveyed by color alone.

Fonts are system-installed (Rockwell ≈ NYT's Karnak slab; Georgia for editorial serif) — still a single offline file.

D — The Games Page. Casebook as a modern puzzle brand: the shelf is a games menu where each case gets one identity color and a simple geometric mark; questions are Connections-style flat tiles; verdicts are quiet colored banners; your suspect list is a rail of chips you eliminate. Feels like Wordle/Connections — friendly, fast, zero clutter.
